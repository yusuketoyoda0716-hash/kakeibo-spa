# 家計簿SPAアプリ

React + LocalStorage で作成したシンプルな家計簿アプリです。
スマホUIを意識したSPAとして作成しています。

---

## デモ

https://（VercelのURL）

---

## 使用技術

* React
* Vite
* JavaScript
* Recharts（グラフ）
* LocalStorage

---

## 主な機能

### ① 取引追加（電卓UI）

* テンキー入力
* 支出 / 収入切替
* カテゴリ選択
* メモ保存

### ② ダッシュボード

* 月ごとの収支
* 支出カテゴリの円グラフ
* 支出ランキング

### ③ 取引管理

* 月フィルター
* 編集
* 削除（確認モーダル）

### ④ カテゴリ管理

* カテゴリ追加
* カテゴリ削除

### ⑤ 定期取引

* 毎月の固定費テンプレ
* ワンクリックで反映

---

## 工夫した点

* SPAとして画面遷移なしで操作できるUI
* スマホ操作を意識した電卓型入力
* LocalStorageを利用したデータ管理
* 再利用可能なカスタムHook設計
